# 相机色彩矫正标定系统



## 1. 项目简介
本项目是一个工业级的相机颜色标定与生成指定标定文件的工具。它通过对比标准数字模板（图像LAB数值）与
相机实际采集图像（图像RGB数值）, 建立颜色映射模型，并生成 LUT（查找表）以校正相机拍摄的图片颜色。
主要应用场景包括工业印刷检测、色彩还原测试及相机ISP参数调优。



## 2. 核心功能
- 自动特征匹配：使用 OpenCV 模板匹配自动对齐模板图与采集图。
- 鲁棒的网格提取：基于 HLS 亮度分量、Canny 边缘检测及距离变换算法，自动提取马赛克/色卡中心点，包含抗噪点干扰的网格校验逻辑。
- 颜色数据提取：自动截取（Crop）色块区域并计算 RGB 均值。
- 生成 RGB 数据 Excel。
- 与标准 LAB 数据（`map.xlsx`）合并。
- 训练颜色映射模型。
- 生成 LUT 查找表。
- 测试：输出校正后的图像。

## 4. 目录结构说明
程序运行依赖严格的目录结构。无论是运行源码还是打包后的 EXE，请确保\*\*同级目录\*\*下存在以下文件夹结构：
```text

Project\_Root/
│
├── run.exe               <-- 双击该程序运行
│
├── 1\_template/          <-- [输入] 存放标准模板图片和map.xlsx（！！！切记勿删）
│   ├── template.jpg
│   └── map.xlsx        
│
├── 2\_capture/           <-- [输入] 存放相机采集的实拍图片（！！！命名方式必须是:match.bmp）
│   └── capture.jpg
│
└── 3\_result/            <-- [输出] 程序自动生成结果
   |
   ├── 1\_test\_temp\_location.jpg  (调试图: 模板定位)
   ├── 2\_test\_insp\_location.jpg  (调试图: 采集图定位)
   ├── 3\_calib\_before.jpg         (调试图：校正前图像)
   ├── 4\_calib\_after.jpg          (调试图：校正后图像)
   └── map\_data\rgb_to_srgb.bin    (最终生成的标定文件，约49M，直接复制设备现有文件即可)

```

## 5) 版本说明：
v1.2.0发布版：
- 新增对矫正图像过曝效果控制模块，让矫正后的图像有一定对比度拉伸，但是白纸区域细小黑色划痕不会因为颜色矫正被淹没。

v1.1.0发布版：
- 软件界面新增功能2，即当生成了所有颜色标定文件后，可以直接调用功能2实现图片色彩验证，
但是必须保证4_test_data/input里面保存了待测试图片，测试图片可以放置任意张数，任意扩展名，最后在4_test_data/output里面查看颜色矫正效果，确保标定文件的正确性。
- 提升了1bit的色卡标定精度。


v1.0.1发布版：
- 添加了logs日志文件夹，用于存储所有运行日志。
- 新增config.ini文件，可以支持参数调整。
- 运行时候，新增功能2，即：如果修改了config.ini文件后，必须执行功能2才能让配置生效


v1.0.0 发布版：色卡标定第一版本。
