# 📷 相机色彩矫正标定系统 (Camera Color Calibration Tool)

本项目是一个工业级的相机颜色标定与生成指定标定文件的工具。它通过对比**标准数字模板（图像LAB数值）**与**相机实际采集图像（图像RGB数值）**, 建立颜色映射模型，并生成 LUT（查找表）以校正相机拍摄的图片颜色。

> **主要应用场景**：工业印刷检测、色彩还原测试及相机 ISP 参数调优。

---

## ✨ 核心功能

*   **🔍 自动特征匹配**：使用 OpenCV 模板匹配自动对齐模板图与采集图。
*   **📐 鲁棒的网格提取**：基于 HLS 亮度分量、Canny 边缘检测及距离变换算法，自动提取马赛克/色卡中心点，包含抗噪点干扰的网格校验逻辑。
*   **🎨 颜色数据提取**：自动截取（Crop）色块区域并计算 RGB 均值。
*   **📊 数据处理与导出**：
    *   生成 RGB 数据 Excel。
    *   与标准 LAB 数据（`map.xlsx`）合并。
    *   训练颜色映射模型。
*   **🛠️ LUT 生成**：生成查找表用于后续校正。
*   **✅ 效果验证**：输出校正后的图像进行对比。

## 📂 目录结构说明

程序运行依赖严格的目录结构。无论是运行源码还是打包后的 EXE，请确保 **同级目录** 下存在以下文件夹结构：

```text
Project_Root/
│
├── run.exe                    # [程序入口] 双击该程序运行
│
├── 1_template/                # [输入] 存放标准模板图片和 map.xlsx
│   ├── template.jpg           #      (！！！切记勿删)
│   └── map.xlsx
│
├── 2_capture/                 # [输入] 存放相机采集的实拍图片
│   └── match.bmp              #      (！！！命名方式必须是: match.bmp)
│
├── 3_result/                  # [输出] 程序自动生成结果
│   ├── 1_test_temp_location.jpg   # 调试图: 模板定位
│   ├── 2_test_insp_location.jpg   # 调试图: 采集图定位
│   ├── 3_calib_before.jpg         # 调试图：校正前图像
│   ├── 4_calib_after.jpg          # 调试图：校正后图像
│   └── map_data/
│       └── rgb_to_srgb.bin        # 最终生成的标定文件 (约49M，直接复制到设备)
│
└── 4_test_data/               # [测试] 用于验证标定效果
    ├── input/                 #      放入待测试图片 (任意名称/格式)
    └── output/                #      生成校正后的图片
```

## 📅 版本历史

### v1.2.0 发布版
*   ✨ **新增功能**：矫正图像过曝效果控制模块。
    *   让矫正后的图像有一定对比度拉伸，同时保留白纸区域细小黑色划痕，避免因颜色矫正被淹没。

### v1.1.0 发布版
*   ✨ **新增功能**：图片色彩验证 (功能2)。
    *   生成颜色标定文件后，可直接调用功能2验证效果。
    *   需在 `4_test_data/input` 放入待测图片，结果输出至 `4_test_data/output`。
*   🚀 **优化**：提升了 1bit 的色卡标定精度。

### v1.0.1 发布版
*   📂 **日志系统**：添加 `logs` 文件夹，存储所有运行日志。
*   ⚙️ **配置支持**：新增 `config.ini` 文件，支持参数调整。
    *   注意：修改配置后需执行功能2才能生效。

### v1.0.0 发布版
*   🎉 **初始版本**：色卡标定第一版本。
