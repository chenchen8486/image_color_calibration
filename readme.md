# 相机色彩矫正标定系统 (Camera Color Calibration Tool)

本项目是一个工业级的相机颜色标定与生成指定标定文件的工具。它通过对比**标准数字模板（图像LAB数值）**与**相机实际采集图像（图像RGB数值）**, 建立颜色映射模型，并生成 LUT（查找表）以校正相机拍摄的图片颜色。

> **主要应用场景**：工业印刷检测、色彩还原测试及相机 ISP 参数调优。

---

## 核心功能

### 自动特征匹配
系统采用两层匹配策略对模板图与采集图进行对齐。首先对下采样后的图像进行粗匹配，快速定位大致区域；随后回到原始分辨率，在局部区域内进行精匹配，既保证匹配速度又保证定位精度。匹配过程中的缩放比例、搜索边距比例以及最低匹配得分阈值均可通过 `config.ini` 文件灵活调整，以适应不同分辨率和拍摄条件下的图像对。

### 鲁棒的网格提取
针对色卡/马赛克网格的自动提取，系统构建了一套完整的图像处理链路：先将图像转换至 HLS 色彩空间并提取亮度分量，经 CLAHE 自适应直方图均衡增强局部对比度后，使用高斯模糊抑制噪点，再通过 Canny 边缘检测获取色块边界；随后利用形态学闭运算连接断裂边缘，基于距离变换计算各区域到边界的距离，最终通过局部峰值检测（peak local max）锁定每个色块的中心点。

考虑到实拍环境可能存在脏污、反光或噪点干扰，系统额外实现了网格校验机制：以 49 行 × 33 列的理论网格位置为基准，计算检测到的中心点相对于理论网格的中值偏移量，对整体网格进行平移修正；对于偏移后仍缺失的网格点，通过最近邻匹配在限定距离内寻找替代点，从而在不依赖人工干预的情况下获得完整且规律的网格中心点阵列。

### 颜色数据提取
在获得准确的网格中心点后，系统以每个中心点为圆心，按照配置的半径（默认为 30 像素）截取正方形区域作为该色块的采样 Patch。对每个 Patch 内的所有像素，分别计算 BGR 三个通道的算术平均值，得到该色块的平均颜色响应。所有色块的均值数据最终会经过 BGR 到 RGB 的格式转换，统一以 RGB 顺序存储，便于与标准数据对齐。

### 数据处理与导出
系统将提取到的 RGB 数据与标准 LAB 数据（来源于 `1_template/map.xlsx`）按行对齐合并。`map.xlsx` 中必须包含 `LAB_L`、`LAB_A`、`LAB_B` 三列标准值。合并后生成的 Excel 文件包含 `R`、`G`、`B`、`LAB_L`、`LAB_A`、`LAB_B` 等完整字段，作为后续机器学习模型训练的标准输入数据集。同时，系统会对行数不匹配的情况发出警告，并以最小有效行数进行数据合并，防止因个别色块识别失败导致整个流程中断。

### LUT 生成
基于训练完成的多层感知机（MLP）回归模型，系统会对所有可能的 RGB 组合进行预推理。对于 8bit 位深，模型会遍历 256³ 共 16,777,216 种 RGB 输入，预测其对应的 LAB 输出，再经由 LAB → sRGB 色彩空间转换，得到最终的 sRGB 校正结果。所有预计算结果以二进制格式写入查找表文件 `rgb_to_srgb.bin`（体积约 49MB）。设备端在实际运行时只需进行简单的查表操作，即可在毫秒级完成颜色校正，无需部署和运行复杂的神经网络模型。

### 效果验证
生成 LUT 后，可通过系统的功能 2 对任意图片进行批量推理验证。该模块加载已生成的 `rgb_to_srgb.bin` 标定文件，对 `4_test_data/input/` 目录下的所有待测图片执行逐像素查表校正，并将校正后的结果保存到 `4_test_data/output/` 目录。用户可通过对比校正前后的图像，直观评估标定效果，确认颜色还原是否满足预期。

## 代码调用流程

以下为从输入准备到最终输出的完整代码调用链路：

```text
输入准备
├── 1_template/template.jpg  (标准色卡模板图)
├── 1_template/map.xlsx      (标准LAB数值表)
└── 2_capture/match.bmp      (相机实拍图，文件名必须固定)
    │
    ▼
功能1: 训练与标定
├── Step1: 加载模板图 → 逆时针旋转90° → 提取49×33网格中心点
│           └── 输出: 3_result/1_test_temp_location.jpg
├── Step2: 加载实拍图 → OpenCV模板匹配(粗匹配+精匹配) → 裁剪ROI
│           → 逆时针旋转90° → 提取网格中心点
│           └── 输出: 3_result/2_test_insp_location.jpg
├── Step3: 按网格中心点截取Patch → 计算每个色块BGR通道均值
├── Step4: BGR → RGB格式转换
├── Step5: 与map.xlsx中的标准LAB数据按行对齐合并 → 生成Excel
│           └── 输出: 3_result/map_data_result.xlsx
├── Step6: MLP回归模型训练 (输入: RGB → 输出: LAB)
│           └── 输出: 3_result/mlp_regressor_model.pkl, scaler_*.pkl
└── Step7: 基于训练好的模型生成LUT查找表 → rgb_to_srgb.bin
            └── 输出: 3_result/map_data/rgb_to_srgb.bin (约49MB)
    │
    ▼
功能2: 批量推理验证 (可选)
├── 读取 4_test_data/input/ 目录下的待测图片
├── 逐像素查LUT表进行颜色校正
└── 输出校正结果到 4_test_data/output/
```

## 打包指南（如何把源码变成可执行文件）

如果你想把这个项目打包成一个可以直接发给其他人使用的程序，不需要懂编程，只要按照下面的步骤操作即可。项目根目录下已经准备好了一个"一键打包脚本" `build.bat`，你只需要双击运行它，然后等待即可。

### 打包前准备（只需做一次）

**第一步：确认电脑上安装了 Python**

1. 在键盘上同时按下 `Win + R` 键，会弹出一个"运行"窗口。
2. 在输入框中输入 `cmd`，然后按回车键，会打开一个黑色的命令提示符窗口。
3. 在黑色窗口中输入以下命令，然后按回车：
   ```
   python --version
   ```
4. 如果窗口显示类似 `Python 3.x.x` 的字样，说明 Python 已安装，可以直接进入下一步。
5. 如果窗口提示 "python" 不是内部或外部命令，说明你还没有安装 Python，请先从 [Python 官网](https://www.python.org/downloads/) 下载并安装最新版（安装时请务必勾选 "Add Python to PATH" 选项）。

**第二步：安装 PyInstaller（Python 打包工具）**

1. 保持刚才的黑色命令窗口不要关闭。
2. 在窗口中输入以下命令，然后按回车，等待安装完成：
   ```
   pip install pyinstaller
   ```
3. 安装完成后，窗口会显示 `Successfully installed pyinstaller` 之类的提示。

### 开始一键打包

**第三步：双击运行打包脚本**

1. 打开你的项目文件夹（也就是包含 `run.py`、`build.bat` 等文件的那个文件夹）。
2. 在这个文件夹中，找到一个名为 `build.bat` 的文件。
3. **直接用鼠标双击 `build.bat` 文件**。
4. 系统会弹出一个黑色的命令行窗口，打包过程正式开始。

**窗口中会出现以下提示（请耐心等待，不要关闭窗口）：**

- `[1/4] Checking PyInstaller...` — 脚本正在检查打包工具是否正常。
- `[2/4] Building executable (directory mode -D)...` — **这是最重要的一步，也是最耗时的一步**。程序正在把所有代码和依赖库打包成可执行文件。这个过程根据电脑性能不同，通常需要 **3~10 分钟**。在此期间，黑色窗口可能看起来没有变化，这是正常的，请不要关闭它，也不要做任何操作，只需等待。
- `[3/4] Preparing required folders and files...` — 打包已完成，脚本正在自动把项目运行必需的文件夹（如 `1_template`、`2_capture` 等）和配置文件复制到分发目录中。
- `[4/4] Verifying build result...` — 脚本正在检查最终生成的文件是否完整。

**打包完成**

当窗口中出现以下字样时，表示打包已经成功：

```
========================================
  Build Success!
========================================
```

同时窗口会显示分发目录的位置：`dist\ColorCalibrationTool\`。此时按键盘上的任意键，窗口就会自动关闭。

> **温馨提示：为什么打包后不是一个单独的 `.exe` 文件，而是一整个文件夹？**  
> 这是因为我们使用的是"目录模式"打包。如果把所有依赖库都塞进一个 `.exe` 文件里，虽然看起来只有一个文件很简洁，但用户每次双击运行时，电脑都需要先把里面压缩的文件解压到临时目录，这个过程会导致程序启动非常缓慢，可能要等几十秒甚至更久。而目录模式把依赖库放在一个名为 `_internal` 的文件夹中，程序可以直接读取，启动速度快得多，使用体验更好。所以请务必以整个文件夹的形式分发，而不是只拷贝一个 `.exe` 文件给别人。

### 打包完成后在哪里找到程序

打包成功后，在项目文件夹中会多出一些新的内容：

- `build/` — 这是打包过程中产生的临时文件，可以手动删除，不影响使用。
- `dist/ColorCalibrationTool/` — **这就是最终的分发包**，里面已经包含了运行程序所需的一切。

`build.bat` 脚本已经自动帮你把所有必需的文件复制到了分发目录中，你不需要手动复制任何东西。最终的分发目录结构如下：

```text
dist/ColorCalibrationTool/          # 最终分发包文件夹
│
├── ColorCalibrationTool.exe       # [主程序] 双击即可运行
│
├── _internal/                     # [依赖库] 程序运行必需的库文件，不可删除
│
├── 1_template/                    # [必须] 标准模板数据
├── 2_capture/                     # [必须] 相机采集图像
├── 3_result/                      # [输出] 程序自动生成结果
├── 4_test_data/                   # [测试] 验证标定效果
├── logs/                          # [日志] 运行日志存储
├── config.ini                     # [配置] 程序配置文件
└── readme.md                      # [说明] 使用说明文档
```

**注意： `_internal` 文件夹以及 `1_template`、`2_capture` 等文件夹都是程序正常运行所必需的。缺少任何一个，程序都无法启动。**

### 如何把程序发给其他人使用

打包完成后，你不需要做任何额外配置。只需要做一件事：

**将整个 `dist/ColorCalibrationTool/` 文件夹拷贝给对方即可。**

对方使用 Windows 系统的电脑，无需安装 Python，无需安装任何其他软件或运行库，也无需进行任何配置。对方收到文件夹后，双击里面的 `ColorCalibrationTool.exe` 文件，程序就会直接启动。

## 目录结构说明

程序运行依赖严格的目录结构。无论是运行源码还是打包后的 EXE，请确保 **同级目录** 下存在以下文件夹结构：

```text
Project_Root/
│
├── run.exe                    # [程序入口] 双击运行
│
├── 1_template/                # [输入] 标准模板数据
│   ├── template.jpg           # 标准色卡模板图片（请勿删除或重命名）
│   └── map.xlsx               # 标准色卡的 LAB 数值表（必须包含 LAB_L, LAB_A, LAB_B 列）
│
├── 2_capture/                 # [输入] 相机采集图像
│   └── match.bmp              # 实拍色卡图片（文件名必须为 match.bmp）
│
├── 3_result/                  # [输出] 程序自动生成结果
│   ├── 1_test_temp_location.jpg   # 调试图：模板网格中心点定位结果
│   ├── 2_test_insp_location.jpg   # 调试图：实拍图网格中心点定位结果
│   ├── 3_calib_before.jpg         # 调试图：校正前图像
│   ├── 4_calib_after.jpg          # 调试图：校正后图像
│   ├── map_data_result.xlsx       # 合并后的 RGB+LAB 数据表
│   └── map_data/
│       └── rgb_to_srgb.bin        # 最终生成的标定文件（约49MB，可直接复制到设备使用）
│
└── 4_test_data/               # [测试] 用于验证标定效果
    ├── input/                 # 放入待测试图片（支持任意名称/格式）
    └── output/                # 生成校正后的图片（程序自动写入）
```

### 运行前准备
1. 确保 `1_template/` 目录下同时存在 `template.jpg` 和 `map.xlsx`。
2. 确保 `2_capture/` 目录下存在名为 `match.bmp` 的实拍图。
3. 首次运行会自动生成 `config.ini` 和 `logs/` 目录，建议根据实际图像分辨率调整 `config.ini` 中的匹配参数。

### 关于程序分发与交付

如果你是将源码通过 PyInstaller 打包后分发给其他用户使用，那么接收方拿到的应该是 `dist/ColorCalibrationTool/` 这个完整的文件夹，而不是单独的一个 `.exe` 文件。**请务必将整个文件夹（包含 `_internal` 依赖库、以及上述 `1_template`、`2_capture`、`config.ini` 等配套文件）一起拷贝给对方**。对方无需安装 Python，也无需配置任何环境，直接双击文件夹内的 `ColorCalibrationTool.exe` 即可运行。
